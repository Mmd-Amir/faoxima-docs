مرجع خطاها

پیام‌های خطای انگلیسی که ربات، مینی‌اپ و آداپتورهای پنل واقعاً در کد و لاگ خروجی می‌دهند، به‌همراه معنی، علل احتمالی و راه‌حل هرکدام به فارسی:

کد خطا / پیاممعنیعلل احتمالیراه‌حل
HTTP 200 · Successfulدرخواست به API مینی‌اپ با موفقیت انجام شد.——
HTTP 400 · Bad requestورودی درخواست به مینی‌اپ نامعتبر یا ناقص است.پارامتری اشتباه یا با فرمت نادرست به API مینی‌اپ ارسال شده است.ورودی را مطابق فرمت مورد انتظار اصلاح و دوباره ارسال کنید.
HTTP 401 · Authorization header missingهدر احراز هویت در درخواست به API مینی‌اپ ارسال نشده است.هدر Authorization: Bearer اصلاً ارسال نشده است.توکن معتبر کاربر را در هدر درخواست ارسال کنید.
HTTP 401 · Authorization header missing or malformedهدر Bearer توکن مینی‌اپ ارسال نشده یا فرمت آن اشتباه است.هدر Authorization خالی است یا با پیشوند Bearer شروع نمی‌شود.مینی‌اپ را از داخل ربات دوباره باز کنید تا یک نشست (session) معتبر دریافت شود.
HTTP 403 · Token invalidتوکن Bearer ارسالی با هیچ کاربری در سیستم مطابقت ندارد.نشست کاربر منقضی یا نامعتبر شده است.مینی‌اپ را دوباره از داخل ربات باز کنید.
HTTP 403 · Forbiddenدسترسی به این عملیات مجاز نیست.کاربر مسدود شده یا مالک منبع درخواستی نیست.با حساب صحیح وارد شوید؛ در صورت تکرار با پشتیبانی تماس بگیرید.
HTTP 403 · user blockedکاربر توسط ادمین مسدود شده و اجازهٔ استفاده از مینی‌اپ را ندارد.وضعیت کاربر در دیتابیس روی block تنظیم شده است.در صورت اشتباه بودن مسدودی، با پشتیبانی یا ادمین ربات تماس بگیرید.
HTTP 404 · Not foundمنبع درخواستی در API مینی‌اپ پیدا نشد.شناسهٔ درخواستی نامعتبر است یا حذف شده.شناسهٔ درخواستی را بررسی کنید.
HTTP 405 · Method invalid; must be {method}متد HTTP درخواست با آنچه endpoint انتظار دارد مطابقت ندارد.درخواست با متدی غیر از متد مجاز (مثلاً GET به‌جای POST) ارسال شده است.متد صحیح را طبق مستندات API استفاده کنید.
HTTP 500 · Internal server errorخطای غیرمنتظرهٔ سرور در پردازش درخواست رخ داده است.استثنای مدیریت‌نشده (uncaught exception) یا خطای بحرانی PHP در کد برنامه.لاگ سرور را بررسی کنید؛ در صورت تکرار با پشتیبانی تماس بگیرید.
Server is not configured (missing bot token)توکن ربات روی سرور تنظیم نشده است.مرحلهٔ نصب/پیکربندی بدون وارد کردن توکن BotFather کامل شده است.توکن ربات را در تنظیمات/سرور ثبت کنید.
Telegram init data is missing or invalidداده‌های اولیهٔ ورود از تلگرام (Telegram WebApp init data) در مینی‌اپ معتبر نیست.مینی‌اپ خارج از محیط تلگرام باز شده، یا امضای init data نامعتبر است.مینی‌اپ را از داخل ربات تلگرام باز کنید، نه از مرورگر مستقل.
Failed to register userثبت خودکار کاربر جدید مینی‌اپ ناموفق بود.خطا هنگام درج رکورد کاربر در دیتابیس.اتصال دیتابیس را بررسی کرده و دوباره تلاش کنید.
Failed to generate session tokenساخت توکن نشست برای کاربر مینی‌اپ ناموفق بود.خطای داخلی در تولید توکن پس از احراز هویت موفق کاربر.دوباره تلاش کنید؛ در صورت تکرار لاگ سرور را بررسی کنید.
Panel Not Foundرکورد پنل در دیتابیس پیدا نشد.پنل هنوز ثبت نشده، یا رکورد آن حذف/غیرفعال شده است.از «مدیریت پنل» پنل را انتخاب یا دوباره ثبت کنید.
User not foundاکانت کاربر روی پنل پیدا نشد.اکانت روی پنل حذف شده یا هرگز ساخته نشده است.وضعیت اکانت را روی پنل بررسی و در صورت نیاز دوباره بسازید.
Username must be at least 3 characters long.نام کاربری وارد‌شده برای ساخت سرویس خیلی کوتاه است.نام کاربری کمتر از سه کاراکتر وارد شده است.نام کاربری با حداقل سه کاراکتر وارد کنید.
[REMNAMWAVE-AUTH-REQ] missing static API token for panelتوکن ثابت API برای پنل Remnawave تنظیم نشده است.هنگام ثبت پنل Remnawave، فیلد توکن API خالی مانده است.توکن API پنل Remnawave را در تنظیمات پنل وارد کنید.
[REMNAMWAVE-PANEL-TEST-FAIL] could not obtain tokenدریافت توکن از پنل Remnawave در تست اتصال ناموفق بود.توکن API نامعتبر است یا پنل درخواست را رد کرده است.توکن API و آدرس پنل را بررسی و دوباره ثبت کنید.
[REMNAMWAVE-PANEL-TEST-FAIL] URL contains extra pathآدرس ثبت‌شدهٔ پنل Remnawave شامل مسیر اضافی است.آدرس پنل با بخش‌هایی مثل /dashboard وارد شده، در حالی که فقط باید دامنهٔ پنل وارد شود.فقط دامنهٔ پنل را بدون مسیر اضافی وارد کنید.
[REMNAMWAVE-PANEL-TEST-FAIL] Non-JSON response (likely dashboard URL)پاسخ پنل Remnawave در تست اتصال، JSON معتبر نبود.آدرس واردشده به داشبورد وب پنل اشاره دارد نه به آدرس API.آدرس صحیح API پنل (نه آدرس داشبورد) را وارد کنید.
authentication failedاحراز هویت با پنل Remnawave در زمان ساخت سرویس ناموفق بود.توکن API معتبر نیست یا در دسترس نبود.توکن API پنل را بررسی و دوباره ثبت کنید.
[REMNAWAVE-ADMIN-ERROR]خطا هنگام یک عملیات ادمین روی پنل Remnawave رخ داده است.جزئیات دقیق خطا در متن پیام لاگ‌شده در گروه/تاپیک ادمین ذکر می‌شود.متن کامل پیام خطا در گروه ادمین را بررسی و طبق آن اقدام کنید.
remnawave user not foundکاربر موردنظر در سیستم Remnawave پیدا نشد.اکانت کاربر روی پنل Remnawave حذف شده یا هرگز ساخته نشده است.وضعیت اکانت را روی پنل Remnawave بررسی کنید.
Guard panel not foundرکورد پنل نوع Guard در دیتابیس پیدا نشد.پنل هنوز ثبت نشده یا حذف شده است.پنل Guard را از «مدیریت پنل» دوباره انتخاب یا ثبت کنید.
API key is not configured for this Guard panelکلید API برای پنل Guard تنظیم نشده است.هنگام ثبت پنل، فیلد کلید API خالی مانده است.کلید API پنل Guard را در تنظیمات پنل وارد کنید.
Invalid services response from Guardپاسخ دریافتی از پنل Guard برای فهرست سرویس‌ها نامعتبر بود.پنل Guard در دسترس نیست یا نسخهٔ ناسازگاری اجرا می‌کند.اتصال و آدرس پنل Guard را بررسی کنید.
No services available on Guard panelهیچ سرویسی روی پنل Guard موجود نیست.ظرفیت پنل تکمیل شده یا سرویسی تعریف نشده است.ظرفیت/تنظیمات سرویس‌ها را روی پنل Guard بررسی کنید.
Invalid JSON responseپاسخ دریافتی از پنل، JSON معتبر نبود.آدرس یا پورت پنل اشتباه است، یا پنل پاسخ غیرمنتظره‌ای برگردانده است.آدرس و پورت پنل را بررسی کنید.
client not foundکاربر موردنظر در پنل x-ui/3x-ui پیدا نشد.اکانت روی پنل حذف شده یا شناسهٔ آن تغییر کرده است.وضعیت اکانت را روی پنل بررسی کنید.
token mode requiredعملیات درخواست‌شده روی این پنل نیاز به حالت توکن دارد که فعال نیست.پنل با حالت احراز هویت متفاوتی (بدون توکن) پیکربندی شده است.تنظیمات احراز هویت پنل را بررسی کنید.
no active usersهیچ کاربر فعالی برای عملیات گروهی (bulk) پیدا نشد.در بازهٔ زمانی/شرایط تعیین‌شده هیچ اکانت فعالی روی پنل وجود ندارد.شرایط فیلتر را بررسی یا عملیات را روی پنل دیگری اجرا کنید.
Invalid authorityپارامتر Authority بازگشتی از درگاه زرین‌پال معتبر نیست.فرایند بازگشت از درگاه دستکاری یا قطع شده است.پرداخت را دوباره از ابتدا در ربات یا مینی‌اپ آغاز کنید.
Invalid bodyبدنهٔ درخواست بازگشتی (callback) از درگاه پرداخت معتبر نیست.درخواست callback با فرمت نادرست یا ناقص از درگاه دریافت شده است.در صورت تکرار، وضعیت درگاه پرداخت و آدرس callback را بررسی کنید.
Missing signature / Bad signatureامضای امنیتی درخواست بازگشتی از درگاه پرداخت وجود ندارد یا نامعتبر است.کلید مخفی درگاه در تنظیمات با مقدار درگاه مطابقت ندارد.کلید API/مخفی درگاه پرداخت را بررسی و دوباره ثبت کنید.
Order not foundسفارش مرتبط با پرداخت بازگشتی پیدا نشد.شناسهٔ سفارش نامعتبر است یا سفارش قبلاً حذف شده است.وضعیت سفارش را در پنل ادمین بررسی کنید.
Already processedاین پرداخت قبلاً پردازش و تأیید شده است.درخواست بازگشتی (callback) بیش از یک‌بار برای همان پرداخت ارسال شده؛ این حالت به‌صورت ایمن نادیده گرفته می‌شود.نیازی به اقدام نیست؛ موجودی کاربر قبلاً شارژ شده است.
CurlRequest error calling {URL}: Failed to connect to {host} port {port} after {N} ms: Connection refused (HTTP code: 0)اتصال TCP به آدرس پنل برقرار نشد؛ متن خطا مستقیماً از cURL گرفته شده است.پنل خاموش است، پورت اشتباه است، یا فایروال سرور/هاست پنل درخواست را رد کرده است.آدرس، پورت و در دسترس‌بودن پنل را بررسی کنید؛ این خطا فقط در لاگ سرور ثبت می‌شود، نه در پیام کاربر.
CurlRequest error calling {URL}: Operation timed out after {N} milliseconds (HTTP code: 0)اتصال به پنل در بازهٔ زمانی مجاز پاسخ نداد.پنل کند پاسخ می‌دهد، شبکه بین سرور ربات و پنل کند/ناپایدار است، یا پنل در دسترس نیست.در صورت تکرار، بار سرور پنل و اتصال شبکه را بررسی کنید؛ ربات یک‌بار به‌صورت خودکار درخواست را تکرار می‌کند.
Panel temporarily unavailable (HTTP {code}).پنل با کد وضعیت خطای سرور (مثل ۵۰۲/۵۰۳/۵۰۴) پاسخ داده است.سرویس پنل در حال ری‌استارت، اورلود، یا پشت یک ریورس‌پروکسی از کار افتاده است.چند لحظه صبر کرده و دوباره تلاش کنید؛ در صورت تکرار وضعیت سرویس پنل را بررسی کنید.
Panel configuration not found for the provided code.رکورد پنل Marzban با کد واردشده پیدا نشد.کد پنل اشتباه است یا پنل حذف شده است.کد پنل را در «مدیریت پنل» بررسی و در صورت نیاز پنل را دوباره ثبت کنید.
Panel configuration not found for the requested location.هیچ پنل Marzban فعالی برای لوکیشن/محصول انتخاب‌شده تنظیم نشده است.محصول به هیچ پنلی متصل نیست، یا پنل مربوطه غیرفعال/حذف شده است.اتصال محصول به پنل را در تنظیمات محصول بررسی کنید.
Unable to decode panel response.پاسخ دریافتی از پنل Marzban قابل خواندن (decode) نبود.پنل پاسخ غیر-JSON یا خراب برگردانده، معمولاً به‌دلیل خطای داخلی پنل یا آدرس اشتباه.آدرس پنل و لاگ خود پنل Marzban را بررسی کنید.

Invalid response received from Telegram.پاسخ دریافتی از API تلگرام قابل خواندن یا نامعتبر بود.قطعی موقت ارتباط با سرورهای تلگرام، یا فیلترینگ/مسدودی شبکه سرور ربات.اتصال شبکهٔ سرور به api.telegram.org را بررسی کنید؛ معمولاً موقتی است.
Telegram request failed.درخواست ربات به API تلگرام ناموفق بود.خطای شبکه بین سرور ربات و تلگرام، احتمالاً به‌دلیل فیلترینگ یا نبود دسترسی مستقیم.در صورت نیاز، پروکسی یا DNS سرور را برای دسترسی به api.telegram.org بررسی کنید.
❌ خطا در ارتباط با پنل. جزئیات در لاگ [REMNAWAVE-ADMIN-ERROR]عملیات ادمین روی پنل Remnawave در پنل وب/ربات ناموفق بود.خطای API پنل، توکن نامعتبر، یا قطعی اتصال؛ جزئیات دقیق فقط در فایل لاگ سرور ثبت می‌شود.فایل لاگ سرور را برای خط [REMNAWAVE-ADMIN-ERROR] بررسی کنید.

خطاهای اعتبارسنجی ورودی (API مینی‌اپ)

username is requiredنام کاربری سرویس ارسال نشده است.درخواست فهرست لوکیشن‌های تمدید بدون پارامتر username ارسال شده.سرویس را از فهرست سرویس‌های خودتان دوباره انتخاب کنید.
Payment not foundرکورد پرداخت پیدا نشد.order_id با هیچ پرداختی در دیتابیس مطابقت ندارد.شناسهٔ پرداخت را بررسی کنید یا دوباره پرداخت را آغاز کنید.
Service not foundسرویس فعالی با این نام کاربری پیدا نشد.یوزرنیم واردشده متعلق به سرویس فعال کاربر نیست یا سرویس منقضی/حذف شده.نام کاربری سرویس را از پنل «سرویس‌های من» بررسی کنید.
panel not found (invalid id_panel)پنل انتخابی در دیتابیس پیدا نشد.id_panel ارسالی نامعتبر است یا پنل حذف/غیرفعال شده.از «مدیریت پنل» پنل را دوباره انتخاب یا ثبت کنید.
Service data unavailableاطلاعات کانفیگ سرویس در دسترس نیست.دریافت اطلاعات سرویس از پنل ریموت ناموفق یا خالی بوده.چند لحظه بعد دوباره تلاش کنید؛ در صورت تکرار وضعیت پنل را بررسی کنید.
خطاهای دسترسی ادمین (پنل مدیریتی مینی‌اپ)
admin onlyاین عملیات فقط برای ادمین مجاز است.کاربر عادی سعی کرده عملیات مخصوص ادمین (آپلود برند، تنظیمات، ساخت/حذف اعلان) را انجام دهد.با حساب ادمین وارد شوید.

خطاهای پرداخت (درگاه‌ها)
خطا در اتصال: {پیام cURL انگلیسی، مثل Could not resolve host / Connection timed out}اتصال به سرور زرین‌پال برای تأیید پرداخت برقرار نشد.خطای شبکه در سطح cURL هنگام تماس با API زرین‌پال (DNS، قطعی، گواهی SSL و مشابه)؛ متن انگلیسی خام cURL بعد از این پیام درج می‌شود.در صورت تکرار، اتصال شبکهٔ سرور به درگاه پرداخت را بررسی کنید.
$result['message'] (پیام انگلیسی خام از درگاه)درگاه زرین‌پال درخواست تأیید پرداخت را رد کرده و دلیل را به انگلیسی برگردانده است.پرداخت ناموفق، لغوشده، یا مبلغ/شناسهٔ نامعتبر از دید خود درگاه.پیام دقیق بازگشتی از درگاه را در لاگ بررسی کنید.
⭕️ خطا در ساخت لینک اقای پرداخت ✍️ دلیل خطا : {reason}ساخت لینک پرداخت در درگاه آقای پرداخت (کارت‌به‌کارت هوشمند) ناموفق بود.پاسخ درگاه ناموفق بوده یا خطای شبکه رخ داده؛ متن دقیق (اغلب انگلیسی) از خود درگاه در پیام درج می‌شود.تنظیمات و اتصال درگاه آقای پرداخت را بررسی کنید؛ فقط در گروه ادمین دیده می‌شود.
خطاهای پنل‌های ریموت (فقط لاگ/گروه ادمین)
User Not Found / User UUID Not Foundرکورد کاربر یا شناسهٔ UUID او روی پنل Remnawave پیدا نشد.عملیات (تمدید، تغییر حجم، فعال/غیرفعال‌سازی، حذف) روی کاربری اجرا شده که رکورد محلی‌اش panel_uuid ندارد یا حذف شده.وضعیت اکانت را روی پنل Remnawave و جدول remnawave_users بررسی کنید.
create failed / create failed ({code})ساخت کاربر روی پنل Remnawave ناموفق بود.پاسخ API ساخت کاربر Remnawave غیر ۲۰۰/۲۰۱ بوده یا فیلد پیام نداشته؛ کد HTTP خام در پرانتز درج می‌شود.توکن API، Squad ID و اتصال پنل Remnawave را بررسی کنید.
fetch failed / revoke failed / invalid daysعملیات دریافت اطلاعات کاربر، ابطال لینک اشتراک، یا تمدید گروهی روی Remnawave ناموفق بود.فراخوانی API مربوطه شکست خورده، یا مقدار روزهای تمدید نامعتبر (صفر یا منفی) ارسال شده.لاگ سرور و پارامترهای ارسالی به عملیات را بررسی کنید.
Guard API key is missing / Unable to connect to Guardکلید API پنل Guard تنظیم نشده یا اتصال به آن برقرار نشد.هنگام نرمال‌سازی تنظیمات پنل، فیلد کلید خالی است یا تست اتصال بدون پیام مشخص شکست خورده.کلید API و آدرس پنل Guard را در تنظیمات پنل بررسی کنید.
No valid service id provided / Invalid auto renewal format / Invalid numbers in auto renewalپارامترهای ارسالی برای ساخت/به‌روزرسانی سرویس یا تنظیمات تمدید خودکار روی Guard نامعتبرند.مقدار service_ids قابل تفسیر نیست، یا تنظیمات تمدید خودکار فرمت/اعداد نامعتبر دارند.تنظیمات محصول/سرویس مرتبط با پنل Guard را بررسی کنید.
Unknown panel errorپنل x-ui/3x-ui خطایی بدون پیام مشخص برگردانده است.پاسخ API با success:false اما بدون فیلد msg دریافت شده.لاگ درخواست را برای جزئیات بیشتر بررسی کنید.
HTTP {code} (خام) / invalid responseپاسخ پنل x-ui/3x-ui در حالت token mode ناموفق یا ناقص بود.کد HTTP غیر ۲۰۰ بدون بدنهٔ قابل استفاده، یا پاسخ ۲۰۰ اما بدون فیلد success/obj.اتصال و نسخهٔ پنل x-ui/3x-ui را بررسی کنید.
Inbound Not Found For Emailاینباند مرتبط با کاربر روی پنل x-ui/3x-ui پیدا نشد.این پیام مستقیماً از خود پنل x-ui برمی‌گردد؛ ربات آن را برای تلاش خودکار جهت ترمیم اینباند شناسایی می‌کند.در صورت تکرار، اینباندهای پنل را دستی بررسی کنید.
قالب‌های گزارش خطا در گروه ادمین
خطای تمدید سرویس · نام پنل: {panel} · نام کاربری سرویس: {username} · دلیل خطا: {reason}تمدید سرویس روی پنل ریموت ناموفق بود.{reason} همان پیام خام (اغلب انگلیسی) بازگشتی از پنل هنگام تمدید است.پیام کامل در گروه ادمین را برای تشخیص پنل و علت دقیق بررسی کنید.
خطای خرید حجم/زمان اضافه · نام پنل: {panel} · نام کاربری سرویس: {username} · دلیل خطا: {reason}خرید حجم یا زمان اضافه روی پنل ریموت ناموفق بود.{reason} پیام خام پنل هنگام افزایش حجم/زمان سرویس است.پیام کامل در گروه ادمین را بررسی و پنل مربوطه را تست کنید.
خطاهای داخلی و شبکه (سطح سرور)
Internal error. Check logs/runtime.logخطای مدیریت‌نشده در هستهٔ ربات (نسخهٔ بازنویسی‌شده) رخ داده است.استثنای غیرمنتظره در مسیر کلاسیک ربات/وب‌هوک رخ داده و به‌صورت متن ساده (نه JSON) برگردانده شده.فایل logs/runtime.log را برای جزئیات کامل خطا بررسی کنید.
CurlRequest call to {URL} returned HTTP code {code}پنل با یک کد وضعیت HTTP ناموفق پاسخ داده، بدون اینکه خطای اتصال (cURL) رخ داده باشد.خود اتصال برقرار شده اما پنل کد خطا (۴xx/۵xx) برگردانده است.فقط در لاگ سرور ثبت می‌شود؛ کد HTTP بازگشتی و در دسترس‌بودن پنل را بررسی کنید.
CurlRequest error calling {URL}: {هر پیام خطای cURL}الگوی کلی خطاهای اتصال شبکه به پنل‌ها؛ نمونه‌های رایج «Connection refused» و «Operation timed out» بالاتر آمده، اما این قالب هر خطای دیگر cURL (مثل DNS نامعتبر یا مشکل گواهی SSL) را هم شامل می‌شود.هرگونه خطای سطح شبکه/TLS هنگام تماس ربات با پنل‌های ریموت.فقط در لاگ سرور ثبت می‌شود؛ متن دقیق خطای cURL راهنمای عیب‌یابی شبکه است.
