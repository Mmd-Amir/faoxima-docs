## دربارهٔ این ریپو

این ریپو، **وب‌سایت مستندات** ربات تلگرامی [faoxima](https://github.com/Mmd-Amir/Faoxima) است؛ یک ربات فروش و مدیریت خودکار نمایندگی VPN، ریفکتورشده از سورس متن‌باز **میرزا**. این سایت شامل راهنمای نصب، مهاجرت، مرجع خطاها و توضیح کامل امکانات ربات است — به‌صورت استاتیک (HTML خالص، بدون نیاز به بیلد) و آماده برای هاست روی GitHub Pages یا هر هاست استاتیک دیگر.

### 📄 صفحات مستندات

| فایل | توضیح |
|---|---|
| [`index.html`](./index.html) | صفحهٔ اصلی — معرفی، امکانات، پنل‌های پشتیبانی‌شده، سوالات متداول |
| [`install.html`](./install.html) | راهنمای نصب و راه‌اندازی (سرور اوبونتو و هاست cPanel/aaPanel) |
| [`migrate.html`](./migrate.html) | راهنمای مهاجرت از ربات میرزا |
| [`errors.html`](./errors.html) | مرجع کامل خطاهای ربات و راه‌حل هرکدام |

### ✨ ویژگی‌های کلیدی faoxima

- 📱 **مینی‌اپ تلگرام** — تجربهٔ خرید و مدیریت سرویس به‌صورت اپلیکیشن (SPA) داخل تلگرام
- 💳 **درگاه‌های پرداخت متعدد** — زرین‌پال، ترونادو، تون‌پی، کیوب‌پی، بلوپال، NowPayments و Plisio (کریپتو)
- 🧩 **پشتیبانی چندپنلی** — مرزبان، پاسارگارد، 3x-ui، Remnawave، Guard، Rebecca و فروش دستی
- 🎁 **کد تخفیف و هدیه** برای کاربران و نمایندگان
- 📦 **انبارداری پیشرفته** — فروش دستی عمده، پنل اضطراری، انبار شبکهٔ ملی
- 🎫 **تیکت و پشتیبانی** با دپارتمان‌های قابل تعریف
- 🎨 **پنل وب ادمین** بازطراحی‌شده با ظاهر مدرن

### 🖥️ اجرای محلی

هیچ وابستگی یا مرحلهٔ بیلدی لازم نیست؛ کافی‌ست فایل‌ها را باز کنید:

```bash
git clone <این-ریپو>
cd doc
# با هر سرور استاتیک ساده:
python -m http.server 8080
# یا فقط index.html را در مرورگر باز کنید
```

### 🌓 امکانات فنی سایت

- راست‌به‌چپ (RTL) و فونت وزیرمتن
- حالت روشن / تاریک با ذخیرهٔ خودکار ترجیح کاربر
- طراحی واکنش‌گرا (موبایل تا دسکتاپ)
- بدون فریم‌ورک — HTML/CSS/JS خالص
